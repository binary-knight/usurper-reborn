# Data tables for DataTextScanner (category "data"), one slot per line: kind|file|slot|reason
#   table  the slot's strings reach a player's screen in English: counted
#   nouns  a slot named *Name/*Names holding common nouns (abilities, items, classes, monsters): counted
#   names  proper nouns (NPC, god, boss, place, founder names): not translation targets, not counted
#   keyed  English source or fallback of a Loc key the display resolves first: already translatable, not counted
# A slot says where a literal sits (see DataTextScanner.SlotOf): init.X object initialiser member X,
# decl:X field or local X, new:T#i constructor argument i, init.[k]= dictionary value, dictpair#i
# element i of a { a, b } pair, =X assignment in code, call:M#i argument i of a call to M, and
# /tuple#i for element i of a tuple inside any of these.
# Slots not listed are not counted: ids, keys, SQL, file names, log text, dead code, admin screens,
# and strings already counted as output call arguments (HardcodedTextScanner).
# Not a table, not counted: CombatResult.CombatLog entries. Its only printing reader is
# MainStreetLocation.TestCombat, which has no caller.
# When adding a table of player text, prefer Loc keys; if it must hold English, list it here.
