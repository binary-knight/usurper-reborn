# Usurper Reborn v1.3.15

## Changelist

### Characters

• Fixed a child's last name being replaced on every load when the father has a one word name; a child now keeps the last name it was given (#260)
• Added a Change last name option to a child's menu at Home, for one child or every child at home; a child already renamed keeps that name until it is changed there (#260)
• Adjusted the Home child renames to refuse a name another child, townsperson or player already has; a first name change that worked before can now be refused with "Someone already bears the name" (#261, #262)

### Combat

• Fixed the death menu warning that the next death would erase the character when permadeath is off; it now shows the death count (#260)

### Interface

• Improved boxes, tables and wrapped text for Chinese, Japanese and Korean so they line up by terminal columns (#259)
