Version **1.2.2** translated combat, the item comparison screens and status effects, and changed Temple offerings so they need no good deed and give none back. Version **1.2.1** opened this wiki and the Discord Ask and Suggest commands, and made NPC stat gains and the Iron Rations max HP bonus last. Version **1.2.0** brought Mental health, the rebuilt Temple, Favor, domain boons and permanent stat rewards.

Read the [1.2.2 release notes](https://github.com/binary-knight/usurper-reborn/blob/v1.2.2/DOCS/release-notes/RELEASE_NOTES_1.2.2.md), the [1.2.1 release notes](https://github.com/binary-knight/usurper-reborn/blob/v1.2.1/DOCS/release-notes/RELEASE_NOTES_1.2.1.md) and the [1.2.0 release notes](https://github.com/binary-knight/usurper-reborn/blob/v1.2.0/DOCS/release-notes/RELEASE_NOTES_1.2.0.md) for the complete change lists. Release notes may include story spoilers.

For other versions, see [release notes in the repository](https://github.com/binary-knight/usurper-reborn/tree/main/DOCS/release-notes) and [published releases](https://github.com/binary-knight/usurper-reborn/releases).
