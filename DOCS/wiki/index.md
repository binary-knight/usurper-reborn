Usurper Reborn is a text RPG with a persistent town, character building and a dangerous dungeon. This wiki separates practical advice from generated references. Tables come from the release's built-in definitions, not a live server or a player's save.

## Choose your path

- **New player:** [Getting started](/wiki/en/getting-started/), [your first expedition](/wiki/en/getting-started/first-hour/) and [ways to play](/wiki/en/getting-started/connections/).
- **Build a character:** [Classes](/wiki/en/characters/classes/), [races](/wiki/en/characters/races/), [stats](/wiki/en/characters/stats/), [specializations](/wiki/en/characters/specializations/) and [Mental](/wiki/en/characters/mental/).
- **Look something up:** [Equipment](/wiki/en/items/), [monsters](/wiki/en/monsters/), [gods](/wiki/en/gods/) and [reference rules](/wiki/en/reference/).

## Reading the wiki

The game version and the version used to check each guide appear below its title. Generated numbers follow the exported release. Prose can retain an older checked version until it is reviewed again.

Spoiler disclosures contain secret bosses, divine lore, late story and exact hidden-effect rules. Search and Discord answers do not include disclosure contents. Opening a disclosure is your choice.

English prose launches first. Some entity pages list verified translated names; this does not mean the whole guide has been translated. Each page links to its source code or release notes.
